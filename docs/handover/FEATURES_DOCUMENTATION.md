# Features

1. **Catalog search** — by code (any of `1-1-2-4`, `1/1/2/4`, `01/01/02/04`) or Arabic description words, tolerant of hamza/yaa/taa-marbuta differences.
2. **Section filter chips** — all / ordinary / sanitary / electrical.
3. **"مضاف" badge** on results already in the estimate, with inline +/− qty controls.
4. **Keyboard**: Enter = add first result, Esc = clear.
5. **Estimate table** — serial no., code, full description (wide column on screen, normal width in print), unit, rate, qty (editable), value; delete; move up/down; sort by section.
6. **Custom items** (بند مستجد) with chosen section.
7. **Live summary cards** — per-section totals, grand total, discount, net, plus Arabic tafqeet.
8. **Project metadata** — project name, client, organization, governorate, reference no., discount %, logo upload.
9. **Multiple saved projects** — new / duplicate / delete / switch; JSON export and import.
10. **Excel export** — styled 2-sheet workbook matching the reference GEA layout.
11. **Print / PDF** — A4 print layout with cover + details.
12. **RTL Arabic UI**, responsive layout, toast notifications.
13. **Autosave** in the browser (no account needed).

Not present: user accounts/login, cloud storage of projects, roles, server APIs, direct PDF file generation, Excel import of estimates (catalog updates are done offline by regenerating `items.json`).
