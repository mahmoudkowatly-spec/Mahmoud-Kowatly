# Project Structure

```text
.
├── .env.example                 Placeholder env vars (real .env is not committed)
├── AGENTS.md                    Notes for AI agents working on the repo
├── README.md                    Overview + quick start
├── package.json / bun.lock      Dependencies (exact resolved versions in bun.lock)
├── bunfig.toml                  Bun install settings
├── components.json              shadcn/ui generator config
├── eslint.config.js, .prettierrc, .prettierignore
├── tsconfig.json                TS config, alias "@/*" -> "src/*"
├── vite.config.ts               Uses @lovable.dev/vite-tanstack-config preset (see MIGRATION_GUIDE)
├── drizzle/                     Empty, auto-managed migration journal (no schema)
├── supabase/config.toml         Backend project id only
├── public/
│   ├── favicon.ico
│   └── data/items.json          THE PRICE CATALOG: 5,622 items (~3.6 MB)
├── docs/handover/               This handover package
└── src/
    ├── router.tsx               Creates router + React Query client
    ├── routeTree.gen.ts         AUTO-GENERATED by the router plugin; do not edit
    ├── server.ts                SSR entry, wraps errors into a friendly page
    ├── start.ts                 TanStack Start instance: error middleware + auth-token middleware
    ├── styles.css               Tailwind v4 theme tokens, print colors, @page A4 rules
    ├── routes/
    │   ├── __root.tsx           HTML shell, global SEO meta, Toaster, 404 + error boundary
    │   └── index.tsx            THE WHOLE APP (search, estimate table, projects, custom items, print view)
    ├── lib/
    │   ├── estimate-utils.ts    Sections, totals, discount, Arabic tafqeet, number formatting
    │   ├── export-estimate.ts   Two-sheet styled Excel export (cover + details)
    │   ├── utils.ts             cn() class helper
    │   ├── error-capture.ts, error-page.ts, lovable-error-reporting.ts   Error reporting helpers
    │   └── __tests__/estimate-utils.test.ts   Vitest suite
    ├── hooks/use-mobile.tsx     Viewport hook
    ├── components/ui/*          shadcn/ui primitives (button, input, card, dialog, ...)
    └── integrations/supabase/*  Generated backend client files (unused by app logic)
```
